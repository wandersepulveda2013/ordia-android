# Decisiones Arquitectónicas y de Diseño

- **Design System**: Se creará un conjunto de componentes con el prefijo `Ordia` (OrdiaButton, OrdiaCard, etc.) para centralizar el diseño y evitar dispersión.
- **Colores**: Base estricta en blanco, negro y grises. Colores secundarios reservados para intenciones semánticas (prioridad, éxito, alerta).
- **Procesamiento de texto**: Todo NLP o detección de intenciones debe ser estrictamente local.
