# Ordía Mega Evolution - Mission

## Objective
Convert Ordía into a radically more polished, powerful, automatic, coherent, and pleasant-to-use Android application, following the "Less is More" principle.

## Key Directives
- Implement a completely new visual system (Typography, Spacing, Shapes, Colors, Animations).
- Transform the app into an adaptive interface (Zero UI, Progressive Disclosure).
- Build the Universal Capture Engine.
- Introduce Clipboard Intelligence (contextual actions based on copied text).
- Create Ordía Keyboard, a true system keyboard with the Ordía Bar.
- Develop the Automation Engine (When X Then Y).
- Evolve the Decision Engine (What Now 2.0/3.0).
- Redesign Notes, Search, and Guardians.
- Improve Onboarding, Home, Accessibility, and Performance.

## Principles
- No "AI design" tropes (unnecessary gradients, excessive shadows, glassmorphism).
- Core functionalities must be offline-first and privacy-focused.
- Work continuously in cycles (Waves).
- Ensure high-quality code, tests, and CI/CD validation.

## Autonomy Guidelines
Execute development in sequential Waves. When one wave finishes, automatically start the next. Do not wait for explicit user instructions unless there is a critical, unsafe blocker. Prioritize tasks according to the priority hierarchy defined in the prompt.
