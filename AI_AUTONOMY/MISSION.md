# Misión

Transformar Ordía en una aplicación de organización y ejecución local-first, minimalista, y automática, ejecutando actualizaciones modulares ("Waves").

## Prioridades (Wave 1: Foundation + Design System)
1. Auditar arquitectura visual y componentes.
2. Definir sistema de colores, espaciado y tipografía consistente.
3. Crear componentes base (OrdiaButton, OrdiaCard, etc.).
4. Asegurar accesibilidad básica y preparativos para el "Universal Capture Engine".
