# MISSION: MEGA EVOLUCIÓN AUTÓNOMA DE ORDÍA

Convert Ordía into a radically more polished, powerful, automatic, coherent, and pleasant-to-use Android application.

## Core Principle: LESS IS MORE.
- Simple on the outside, deep on the inside.
- Fast, elegant, personal, modern, coherent, intelligent, automatic, human, premium.
- Complexity appears only when the user needs it.

## Key Directives:
- Full Visual Redesign (typography, spacing, shapes, meaningful colors (no rainbows), own motion language).
- Adaptive Interface (Zero UI, focus mode, command bar, universal capture, intention navigation).
- Universal Capture Engine (text, voice, clipboard, image, etc. to tasks, notes, reminders, events).
- Clipboard Intelligence (detect activities, dates, times, and offer actions while respecting privacy).
- Ordía Keyboard (Real Android keyboard with a minimalist contextual bar and smart actions).
- Automation Engine (WHEN X THEN Y).
- Decision Engine (Answer "What do I do now?", "What can I postpone?").
- What Now 2.0 (One main recommendation with reasoning).
- Guardians Reinvention (Specific responsibilities, memory, autonomous actions).
- Notes (Like Notion + Keep but simpler).
- Universal Search.
- Onboarding (Short, premium, contextual).
- Home Redesign (Now, Later, Today).
- Microinteractions.
- Accessibility & Performance.
- Offline First & Privacy (Local processing first).
- Avoid "AI Design" Tropes (No unnecessary gradients, emojis, generic dashboards).
- Custom Design System (OrdiaButton, OrdiaCard, etc.).
- Adversarial Testing (10k tasks, corrupt data, offline, edge cases).

## Autonomy & Workflow:
- Work in Cycles (Audit, detect, prioritize, design, implement, test, correct, document, integrate, next).
- Prioritize: P0 (bugs/crashes) > P1 (data loss) > P2 (core experience) > ...
- Divide work into Waves (e.g., Wave 1: Foundation + Design System, Wave 2: Home + Navigation...).
- A feature is done when it works, has coherent UX, handles errors/loading, has tests, respects accessibility/privacy.
- Make decisions autonomously on visual architecture, layouts, components, etc., preserving identity and user data.
