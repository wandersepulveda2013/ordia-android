# Wave 1: Foundation and Design System

## Goals:
- Refine the core typography, colors, and shapes in `Theme.kt` and `Type.kt`.
- Create or update base visual components (e.g., `OrdiaButton`, `OrdiaCard`, `OrdiaSurface`) in `AppComponents.kt`.
- Implement a more constrained color palette using only semantic colors against a white/black/gray base.
- Improve spacing and layout in common UI components.
- Fix UI issues based on the 'less is more' philosophy.
