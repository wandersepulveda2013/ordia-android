# Backlog de Evolución Ordía

- Auditoría de Base de Datos y concurrencia (evaluar riesgos de pérdida de datos).
- Sincronización y manejo de Recordatorios (Doze, reinicios, cambios de zona).
- Actualización automática desde GitHub Releases (verificar integridad y firmas).

## P1 (Mejoras funcionales y experiencia)
- Rediseño de Home (TodayScreen) para responder "¿Qué necesito saber ahora?" y "¿Qué debería hacer ahora?".
- Implementar función estrella "What Now" (motor de sugerencias avanzado).
- Mejorar el parser de lenguaje natural en español (manejo de fechas relativas y complejas).
- Replanificación inteligente tras retrasos de tareas.

## P2 (Funciones adicionales)
- Botón flotante universal (Command Palette / quick action inteligente).
- Búsqueda Universal (rápida, con búsqueda aproximada).
- Rutinas verdaderamente adaptables (ventanas horarias, excepciones).
- Dependencias entre tareas (A antes de B).

## P3 (Pulido)
- Revisión de UX (minimalista blanco y negro, mejor jerarquía, animaciones).
- Resúmenes (Mañana, Noche, Semanal).
- Optimización de rendimiento y accesibilidad (TalkBack, fuentes grandes).
