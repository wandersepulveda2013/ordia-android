# Producto Ordia

## Propuesta

Ordia reduce la fricción entre pensar algo y organizarlo. La app no obliga a construir bases de datos complejas: captura primero, ayuda a decidir después y mantiene visible el siguiente paso.

## Principios

1. **Simple al inicio:** los campos avanzados aparecen cuando hacen falta.
2. **Local primero:** tareas, notas y preferencias no dependen de una cuenta.
3. **Accionable:** cada pantalla prioriza una acción concreta.
4. **Adaptable:** la profundidad de la interfaz puede cambiar sin perder datos.
5. **Compañero, no vigilante:** el guardián acompaña sin inspeccionar otras apps.
6. **Sin funciones falsas:** cada control visible debe tener efecto persistente.

## Superficies principales

### Hoy

Resume tareas relevantes, hábitos, progreso y la recomendación determinista del guardián. La recomendación se calcula localmente a partir de atrasos, prioridad, calendario y hábitos pendientes.

### Captura y bandeja

Permite registrar rápidamente una tarea o nota desde la app, el widget, el guardián, el menú Compartir o el procesamiento de texto de Android.

### Tareas y planificador

Incluye subtareas, prioridades, proyectos, etiquetas, duración, recordatorios, repetición, archivo y planificación automática local dentro de una ventana horaria.

### Proyectos

Agrupa tareas y notas, calcula progreso y permite pausar, completar o archivar.

### Notas

Editor por bloques con texto, encabezados, listas, listas de verificación, citas y código. Admite plantillas, adjuntos y guardado automático.

### Hábitos y rutinas

Registra hábitos por período, calcula rachas y permite definir rutinas con pasos ordenados.

### Enfoque

Temporizador asociado opcionalmente a una tarea, historial de sesiones y duración predeterminada configurable.

### Guardián

Superposición opcional con modos Dormido, Discreto y Compañero. Puede abrir captura rápida, enfoque o la app. El usuario controla el permiso y las horas de silencio.

## Alcance 1.0

La versión 1.0 es individual y local. No incluye colaboración multiusuario, sincronización propia en la nube, IA generativa remota ni lectura del contenido de otras aplicaciones.
